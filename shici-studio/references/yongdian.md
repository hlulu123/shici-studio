# 用典

## 1. 为什么用典

- **以少胜多**：一个典故里装着一整段故事。写"冯唐易老"四个字，读者就会想起一个人一辈子怀才不遇。
- **增加厚度**：把今天的事接到历史和文化的长河里，让一首小诗有了纵深。
- **含蓄**：有些话直说太露、太重，借古人的事来说，体面而有分寸。

要记住：典故是为立意服务的手段。先想清楚这首诗要说什么（见 `liyi.md`），再找能帮它说话的典故。不要先挑一个漂亮的典故，再硬凑一首诗去装它。

## 2. 用典的手法

### 明用

直接点出人名、事名，读者一看就知道用了典。

- 王勃《滕王阁序》："冯唐易老，李广难封。"
- 辛弃疾《永遇乐》："凭谁问：廉颇老矣，尚能饭否？"

明用的好处是清楚有力，适合用在想把话说重、说透的地方。

### 暗用

不点名，把典故化进句子里，懂的人自然能读出来，不懂的人也能读通字面。

- 王勃："物华天宝，龙光射牛斗之墟"，暗用《晋书・张华传》丰城剑气的典故。
- 李商隐《锦瑟》："沧海月明珠有泪，蓝田日暖玉生烟"，暗用鲛人泣珠和蓝田玉烟。

暗用更含蓄、更雅，但要保证字面本身读得通。

### 化用

把前人的句子或文意化成自己的句子。

- 李白"大鹏一日同风起，扶摇直上九万里"，化用《庄子・逍遥游》"抟扶摇而上者九万里"。
- 王勃"落霞与孤鹜齐飞，秋水共长天一色"，化用庾信《马射赋》"落花与芝盖同飞，杨柳共春旗一色"，但青出于蓝。

化用要有新意。只换几个字、照搬句式，就成了抄袭。化用之所以好，是因为句子成了你自己的；一首诗若大半句子都是典籍原文略改几字，读者看到的只是一份典故清单。化用名句之后，用 `dupcheck.py` 检查一下，确认没有连续五个字以上与原句相同。如果是有意保留原句，就在说明里交代清楚。

### 反用（翻案）

借典故的原意，反其道而行之。

- 王勃："酌贪泉而觉爽"。传说喝了贪泉的水就会变得贪婪，王勃反过来说喝了反而神清气爽，表明自己的清白。
- 王勃："阮籍猖狂，岂效穷途之哭！"阮籍走投无路时痛哭而返，王勃说自己不学他。
- 杜牧《题乌江亭》："卷土重来未可知"，翻了"项羽无颜见江东父老"的案。

反用最能出新意，也最能见出作者的个性。

### 叠用（合用）

一联之内用两个典故，彼此对仗、互相映衬。

- 王勃："冯唐易老，李广难封。屈贾谊于长沙，非无圣主；窜梁鸿于海曲，岂乏明时？"
- 刘禹锡《酬乐天扬州初逢席上见赠》："怀旧空吟闻笛赋，到乡翻似烂柯人。"上句用向秀《思旧赋》（闻笛怀念亡友），下句用王质烂柯（恍如隔世）。

律诗的颔联、颈联最适合用典对。

### 以典自况

把自己比作典故里的人物，让典故成为"我"的一部分。李白一生以大鹏自比，这是用典的最高境界之一：典和人合为一体（见 `styles/taibai.md`）。

## 3. 用多少

| 体裁、类型 | 建议用典量 | 说明 |
|---|---|---|
| 生活诗、写景诗 | 0—1 处 | 贵在真、贵在新。不用典也完全可以 |
| 绝句 | 1—2 处 | 四句诗，一个典故已经很重了 |
| 律诗 | 1—4 处 | 多放在颔联、颈联，构成典对 |
| 词 | 1—3 处 | 辛弃疾一路可以多用，婉约一路宜少 |
| 定场诗、赠诗 | 1—4 处 | 以人物比附为主 |
| 骈文、序、赋 | 可以很密集 | 几乎句句有典，但每个典故都要切题 |
| 怀古诗 | 视情况而定 | 写史本身就是用典，要保证史实准确 |

## 4. 选典的原则

- **切**：
  - 切题：典故和诗的主题相关。
  - 切人：典故和对象的身份、领域相合。送医生用杏林，送老师用杏坛。
  - 切时：节令典故要对上季节。
  - 切地：写某地就用与此地有关的典故，送人去江南用莼鲈，去西北用阳关、玉门。
- **熟**：常见的典故读者一看就懂；僻典读者看不懂，等于没用。确实需要用僻典时，在典故注里讲清楚。
- **准**：典义不能用反，褒贬不能弄错。
  - "东床"指女婿，不能用来祝福新娘。
  - "结发"在婚诗里指原配夫妻，在李白"结发受长生"里指少年时。
  - "七月流火"出自《诗经・豳风・七月》，说的是大火星西沉、天气转凉，不是指天气炎热。
  - "空穴来风"出自宋玉《风赋》，原意是有了空穴才有风，比喻事出有因，不是指毫无根据。
  - "差强人意"出自《后汉书・吴汉传》，意思是"大体还能使人满意"，不是"不能使人满意"。
- **新**：常见的典故要用出新意，比如反用，或者换一个角度用。
- **避忌**：
  - 婚礼不用长门、破镜。
  - 寿诗不用薤露、蒿里（这两首都是古代挽歌）。
  - 送别不用易水，除非真的是去赴一件悲壮的事。

## 5. 两种用典风格：太白式与滕王阁式

| | 太白式 | 滕王阁式 |
|---|---|---|
| 代表 | 李白《上李邕》《梦游天姥吟留别》 | 王勃《滕王阁序》 |
| 典源 | 以庄子、楚辞、神话、游仙为主 | 以史书、人物故事为主 |
| 密度 | 疏而大：一首诗围绕一两个大意象展开 | 密而工：几乎句句有典，两两成对 |
| 典与人 | 典故被"我"驱使，往往以典自况（大鹏就是李白） | 以典叙身世，借古人的遭遇说自己的处境 |
| 效果 | 气势磅礴、浪漫飞扬 | 典雅富丽、厚重工整 |
| 适合 | 言志、意气风发、歌行、豪情 | 正式场合、序、赠诗、怀古、骈文、庄重的定场诗 |

怎么选：抒怀言志、要气势，走太白式；庄重典雅、要厚度，走滕王阁式。两种也可以结合，比如律诗的颔联、颈联用滕王阁式的典对，尾联用太白式的大意象收住。

## 6. 联网补充与查证

`allusions.md` 收的是常用典故，不是全部。需要的典故不在里面，或者对某个典故的出处没有把握时，按下面的流程做：

1. **先想清楚要表达什么意思**，比如"大器晚成""朋友远道而来""坚守不移"。
2. **查 `allusions.md`**：看看有没有合适的现成典故。
3. **联网搜索**（用 WebSearch）。常用的搜索方式：
   - "<要表达的意思> 典故"，例如"大器晚成 典故"。
   - "<意象> 典故 出处"，例如"白鹤 典故 出处"。
   - "<典故名> 出处 原文"，例如"雪夜访戴 出处 原文"。
4. **核对原文**：找到候选典故后，打开可靠的来源，确认出处的书名、篇名和原文：
   - 首选原典：中国哲学书电子化计划（ctext.org）、维基文库（zh.wikisource.org）。
   - 词语和成语的出处：汉典（zdic.net）。
   - 诗句：古诗文网、搜韵等。这类网站只作参考，最好与原典或别的来源互相印证。
5. **判断能不能用**：典义是什么、是褒是贬、有没有争议（比如作者归属存疑、版本不同）。有争议的地方要在典故注里注明。
6. **写进典故注**（格式见第 7 节）。
7. **查不到可靠出处时**：这个典故就不用，换一个。不要编造出处。
8. **无法联网时**：只用自己有把握的常见典故，并在典故注里标明"出处凭记忆，建议核对"。

引用古人诗句时也要核对：先用 `python3 scripts/dupcheck.py --find "诗句片段"` 或 `--title "诗题"` 在本地诗库里查原文；本地查不到，再联网核对，不要凭记忆直接写进诗里或注里。

## 7. 典故注的格式

交付时，每个典故写一条注：

> ① 扶摇：语出《庄子・逍遥游》"抟扶摇而上者九万里"，以大鹏乘风比喻壮志凌云。
>
> ② 龙光射牛斗：用《晋书・张华传》丰城剑气事。斗、牛之间常有紫气，后来在丰城掘出宝剑，比喻人才终将显露。

要点：

- 标出这个典故在诗中对应的字词。
- 写明出处，具体到书名・篇名；有原文就引一句（20 字以内）。
- 用一句话说明在这首诗里取的是什么意思。
- 有存疑的地方，照实说明，比如"相传""一说"。

## 8. 常见错误

- **张冠李戴**：《滕王阁序》是王勃写的，不是王维；"春风得意马蹄疾"是孟郊的句子，不是李白的。拿不准作者就查。
- **典义误用**：见第 4 节"准"。
- **堆砌**：一句一个典故，彼此没有关系，读者只看到一串人名。
- **僻典不注**：读者看不懂，又没有注释。
- **典故压住真情**：生活诗、柔情诗里用典太多，真情被淹没。
- **编造出处**：宁可不用，也不要编。
