# 藏头诗、藏尾诗、嵌字诗

把指定的字按规律藏进诗里。最常见的是藏头：每句第一个字连起来，读出一句话或一个名字。生日、表白、婚礼、开业、公司周年都常用。

## 1. 几种形式

- **藏头**：每句首字连读。例如藏"春节快乐"四个字，写一首七绝，四句分别以"春""节""快""乐"开头。
- **藏尾**：每句末字连读。由于句末多是韵脚，藏尾诗对用字限制很大，要先确认这几个字能否押韵（见第 3 节）。
- **嵌字**：把字嵌在每句的固定位置。诗钟传统里，按七言的位置有专门的名称：
  - 第一字：凤顶（鹤顶）
  - 第二字：燕颔
  - 第三字：鸢肩
  - 第四字：蜂腰
  - 第五字：鹤膝
  - 第六字：凫胫
  - 第七字：雁足
- **嵌名联**：上下联相同位置各嵌一个字，常用于婚联、店名联、人名联，见 `forms/duilian.md`。
- **斜藏**：第一句第一字、第二句第二字……依次斜着读出。难度大，用户明确要求时再用。

## 2. 选体裁

- 字数决定句数：
  - 4 个字 → 绝句。
  - 8 个字 → 律诗，或者两首绝句。
  - 2 个字 → 对联，或者五言、七言两句。
  - 3 个字、5 个字等不规则字数 → 古风，可以不拘句数；也可以把多出来的字放进题目，或者问用户能不能调整。
- **七言比五言好藏**：七言近体诗每句的第一字都可平可仄，藏头字不受平仄限制。五言的 B 句（平平仄仄平）第一字最好用平声，如果藏头字是仄声，要用"孤平拗救"（第三字用平），或者把这一句安排成别的句式。

## 3. 写法

1. **先列出要藏的字**，用 `meter.py lookup` 查清每个字的平仄。藏尾时还要确认这几个字在不在同一个韵部。
2. **定一个统一的立意**：藏头诗最常见的毛病，是每句只为了把字藏进去，四句之间互不相干。先想好整首诗要说什么（祝福、思念、言志），再让每个字在这个立意里找到位置。
3. **为每个字找一个自然的句子**：
   - 实词（名字、春、山、月等）最好写，可以直接作为句子的主语或意象。
   - 虚词、代词、现代词（的、了、你、我、爱、快、乐等）比较难。办法有：
     - 让它组成一个古今都通的词，如"乐"组成"乐事"，"快"组成"快意"，"爱"组成"爱此"。
     - 让它成为句子的动词或领起的字，如"爱"作"爱看""爱听"。
     - "你"在古典诗里很少见。可以安排在一句通俗的口语里，整首诗走通俗谐趣或闲适浅切的风格；或者问用户能不能接受"君""卿"等代字（这就改变了藏的字，必须征得同意）。
4. **排句式**：根据每个藏头字的平仄，选择合适的谱（平起、仄起），保证粘对。
5. **校验**：跑 `meter.py check`。藏头诗也要合律；如果确实做不到，说明原因，然后用 `--loose` 写成古风。
6. **交付时标出藏的字**：比如把藏头字加粗，或在下面注明"藏头：春节快乐"。

## 4. 例

藏"春节快乐"四个字的七绝，可以这样构思：

- 立意：辞旧迎新，家人团聚。
- 春：春风、春回。可以写成首句，点出时令。
- 节：节里、节序。可以写团聚的场景。
- 快：快意、快饮。第三句转到举杯。
- 乐：乐事、乐此。第四句收在祝福上。

然后为每句选择句式，保证平仄、粘对、押韵都合格，再跑脚本校验。这个例子只是构思的示意，具体的诗要按用户的情况写。

## 5. 常见坑

- **句子之间没有联系**：四句各说各的。
- **藏字生硬**：为了藏字造出不通的句子。宁可换一个说法，也不要让句子不通。
- **只顾藏字，不顾格律**：七言藏头的平仄其实很宽松，没有理由不合律。
- **擅自改字**：用户要藏的字一个都不能少，也不能换。确实难藏的，先和用户商量。
- **藏的字放错位置**：交付前逐句核对首字（或尾字、嵌字）。
