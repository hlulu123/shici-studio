# 对联

对联又叫楹联、对子，由上联和下联组成，常配一个横批。它是对仗艺术的独立形式，使用场合极多：春联、寿联、婚联、挽联、行业联、名胜联、嵌名联。

## 1. 基本规则

1. **字数相等**：上下联字数相同，分句数也相同。
2. **词性相对**：名词对名词，动词对动词，形容词对形容词，数词对数词，虚词对虚词。工对的要求更细，比如天文对天文、颜色对颜色。
3. **结构相称**：主谓对主谓，动宾对动宾，偏正对偏正。
4. **平仄相对**：
   - **句脚**：上联最后一个字用仄声，下联最后一个字用平声，即"仄起平收"。这是最硬的规矩。
   - **节奏点**：句中的节奏点（一般是二、四、六字）上下联平仄相反，句内平仄交替。
   - **多分句的长联**：各分句句脚的平仄按"马蹄韵"排列，上联各分句句脚大体按"平仄仄平平仄"一类的规律交替，最后以仄收；下联与上联相反，以平收。
5. **内容相关**：上下联说的是同一件事、同一个主题，但不能意思重复（合掌）。
6. **避免重字**：上下联之间不要出现无意的重复字。有意的叠字、复字要在上下联相同位置对应出现，比如"风声雨声读书声，声声入耳"。

## 2. 用脚本检查

```bash
python3 scripts/meter.py check --form 对联 "上联；下联"
```

上下联之间用分号或换行隔开。脚本检查三项：字数是否相等、句脚是否仄起平收、节奏点上的平仄是否相对。不符合的地方报为"小疵"或"错误"。

脚本不检查对仗（词性、结构），也不检查长联的马蹄韵，这两项需要自己检查。

名联也常在节奏点上放宽。比如林则徐"海纳百川，有容乃大；壁立千仞，无欲则刚"，第二字"纳""立"同为仄声，脚本会报一个小疵，但句脚仄收平收是严格的。新写的对联，尽量让节奏点平仄相对；实在要放宽，至少守住句脚。

## 3. 对仗的方法

- **声律启蒙式的基本功**："云对雨，雪对风，晚照对晴空。来鸿对去燕，宿鸟对鸣虫。"（车万育《声律启蒙》）
- **工对**：同类词相对，如天文、地理、时令、器物、颜色、数目、方位。
- **宽对**：词性相同即可。
- **流水对**：上下联意思连贯。
- **借对**：借一个字的另一义或谐音成对（见 `craft.md` 第 3 节）。
- **当句对**：联内自对，如"风声雨声读书声"。
- **嵌字**：把名字、店名嵌入上下联相同位置（见 `forms/cangtou.md`）。

## 4. 各类对联要点

| 类型 | 要点 | 避忌 |
|---|---|---|
| 春联 | 辞旧迎新、吉祥、切合当年生肖或时事；可加横批 | 不吉的字词 |
| 寿联 | 切合年龄（雅称见 `types/zhusong.md`）、身份、德行；常用南山、松鹤、大椿 | 死、病、老、暮 |
| 婚联 | 两姓之好、琴瑟、比翼、桃夭；可以嵌新人名 | 离、散、孤、破镜、长门 |
| 挽联 | 称颂逝者德行，表达哀思；措辞庄重 | 轻佻、谐趣；不要编造逝者生平 |
| 行业联、开业联 | 切合行业特点，可嵌店名 | 太俗的吹捧话 |
| 名胜联 | 切合此地的山水与历史，可以用与此地相关的人物和典故 | 只写景，没有人文 |
| 书房联、座右铭 | 言志、劝学、修身 | 说教太露 |

## 5. 张贴

- 传统贴法：面对大门，上联贴在右边，下联贴在左边，横批从右往左写。现在也有按从左往右的横批贴的，两边要对应：横批从左往右写时，上联贴左边。
- 交付时，标明哪一句是上联、哪一句是下联，以及横批。

## 6. 范例

- 顾宪成题东林书院："风声雨声读书声，声声入耳；家事国事天下事，事事关心。"
  - 当句对，复字对应，上联句脚"耳"仄，下联句脚"心"平。
- 林则徐自题："海纳百川，有容乃大；壁立千仞，无欲则刚。"
  - 言志联，上联"大"仄收，下联"刚"平收。
- 民间春联："天增岁月人增寿，春满乾坤福满门。"
- 民间寿联："福如东海长流水，寿比南山不老松。"
- 《警世贤文》句，常作励志联："宝剑锋从磨砺出，梅花香自苦寒来。"
