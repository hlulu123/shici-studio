# 近体诗：绝句、律诗、排律

近体诗（格律诗）在唐代成熟，句数、字数、平仄、押韵、对仗都有定规。格律对不对交给脚本判断：`python3 scripts/meter.py check "诗文"`。这份文档讲规则本身，让你在写的时候心里有数，看得懂脚本的报告，也知道该怎么修。

## 1. 体裁一览

| 体裁 | 句数 | 每句字数 | 对仗要求 |
|---|---|---|---|
| 五绝 | 4 | 5 | 不要求 |
| 七绝 | 4 | 7 | 不要求 |
| 五律 | 8 | 5 | 颔联（3、4 句）、颈联（5、6 句）必须对仗 |
| 七律 | 8 | 7 | 同上 |
| 排律 | 10 句以上（偶数） | 5 或 7 | 除首联、尾联外，各联都要对仗 |

## 2. 四种基本句式

近体诗的每一句，都是下面四种句式之一。下面用"平""仄"写出标准平仄；"⊙"表示可平可仄。

**五言**：

| 代号 | 标准 | 放宽写法 | 说明 |
|---|---|---|---|
| A | 仄仄平平仄 | ⊙仄平平仄 | 第三字宜平；第三字用仄是"拗"，第四字用仄是"大拗"，都需要对句来救（见第 5 节） |
| B | 平平仄仄平 | ⊙平⊙仄平 | 第一、三字不能同时用仄，否则犯孤平 |
| C | 平平平仄仄 | ⊙平⊙仄仄 | 第三字用仄可以接受；另有"平平仄平仄"的特殊拗句（见第 5 节） |
| D | 仄仄仄平平 | ⊙仄仄平平 | 第三字必须仄，否则成了"三平尾" |

**七言**：在五言句式前面加两个字，这两个字与五言句的前两字平仄相反。

| 代号 | 标准 | 放宽写法 |
|---|---|---|
| A' | 平平仄仄平平仄 | ⊙平⊙仄平平仄 |
| B' | 仄仄平平仄仄平 | ⊙仄⊙平⊙仄平（第三、五字不能同时用仄） |
| C' | 仄仄平平平仄仄 | ⊙仄⊙平⊙仄仄 |
| D' | 平平仄仄仄平平 | ⊙平⊙仄仄平平（第五字必须仄） |

"一三五不论，二四六分明"是一句粗略的口诀，并不完全准确：孤平、三平尾、拗句都会出在"一三五"上。凡是拿不准的，以脚本为准。

## 3. 绝句的四种谱

句式的排列由三条规则决定：

- **押平声韵**：偶数句必押；首句可押可不押。
- **对**：同一联的上下两句，第二字的平仄相反（七言还要看第四、六字）。
- **粘**：下一联出句的第二字，与上一联对句的第二字平仄相同。

所谓"平起""仄起"，看首句第二字是平还是仄。

**五绝**：

| 格式 | 第一句 | 第二句 | 第三句 | 第四句 |
|---|---|---|---|---|
| 仄起首句不入韵 | 仄仄平平仄 | 平平仄仄平 | 平平平仄仄 | 仄仄仄平平 |
| 仄起首句入韵 | 仄仄仄平平 | 平平仄仄平 | 平平平仄仄 | 仄仄仄平平 |
| 平起首句不入韵 | 平平平仄仄 | 仄仄仄平平 | 仄仄平平仄 | 平平仄仄平 |
| 平起首句入韵 | 平平仄仄平 | 仄仄仄平平 | 仄仄平平仄 | 平平仄仄平 |

**七绝**：

| 格式 | 第一句 | 第二句 | 第三句 | 第四句 |
|---|---|---|---|---|
| 平起首句入韵 | 平平仄仄仄平平 | 仄仄平平仄仄平 | 仄仄平平平仄仄 | 平平仄仄仄平平 |
| 平起首句不入韵 | 平平仄仄平平仄 | 仄仄平平仄仄平 | 仄仄平平平仄仄 | 平平仄仄仄平平 |
| 仄起首句入韵 | 仄仄平平仄仄平 | 平平仄仄仄平平 | 平平仄仄平平仄 | 仄仄平平仄仄平 |
| 仄起首句不入韵 | 仄仄平平平仄仄 | 平平仄仄仄平平 | 平平仄仄平平仄 | 仄仄平平仄仄平 |

例：李白《早发白帝城》是七绝平起首句入韵。"朝辞白帝彩云间"＝平平仄仄仄平平，"千里江陵一日还"＝平仄平平仄仄平（第一字用平，可以），"两岸猿声啼不住"＝仄仄平平平仄仄，"轻舟已过万重山"＝平平仄仄仄平平。

一般来说，五言首句多不入韵，七言首句多入韵。

## 4. 律诗与排律

- **律诗**：把绝句的谱重复一遍，中间照样遵守"粘"的规则。比如七律平起首句入韵，八句依次是 D' B' C' D' A' B' C' D'。第五句不押韵，所以用仄收的 A'。
- **排律**：照律诗的规律往下延长，偶数句押韵，一韵到底。

## 5. 常见的格律问题

脚本会报出下面这些问题。每一项都写了"是什么"和"怎么修"：

| 问题 | 是什么 | 怎么修 |
|---|---|---|
| 出韵 | 韵脚字不在同一个韵部 | 换一个同韵部的韵脚字；或者整首换韵。用 `meter.py rhymes 韵目` 找字 |
| 失对 | 同一联上下句第二字平仄相同 | 换出句或对句第二字（七言还要看四、六字）的平仄 |
| 失粘 | 下联出句第二字与上联对句第二字平仄不同 | 改动出句的平仄；或者调换一联上下句的顺序 |
| 孤平 | 平脚句中，除韵脚外只剩一个平声字（五言看第一到四字，七言看第三到六字） | 把五言第一字（七言第三字）换成平声；或者用"孤平拗救"：五言第三字（七言第五字）改用平声，成为"仄平平仄平"（七言"⊙仄仄平平仄平"） |
| 三平尾 | 句末三个字都是平声 | 把五言第三字（七言第五字）换成仄声 |
| 拗句 | A 句（仄仄平平仄）的第三字或第四字用了仄 | 在对句救：五言对句第三字（七言第五字）改用平声，成为"⊙平平仄平"（七言"⊙仄⊙平平仄平"） |
| 特拗 | "平平仄平仄"（七言"⊙仄平平仄平仄"） | 这是唐人常用的合法句式，不算错。脚本会标出来，不需要修改。五言的第一字宜用平 |
| 重字 | 同一个字在诗中出现两次 | 近体诗忌重字。叠字（如"萧萧"）和有意的反复除外 |
| 首句借邻韵 | 首句韵脚字属于相邻韵部 | 唐宋人常用，属于小瑕疵。脚本只做提醒 |

还有一类是**多音字**：一个字有平、仄两种读音，脚本会取对格律有利的读法，并提示"此处须读X声"。这时你要按字义判断：

- **不别义的两读字**：看、听、忘、叹、醒、望等，平仄两读意思相同，可以按格律需要取。
- **别义的两读字**：读音随意思变，必须按诗里的意思定读音。
  - 思：名词"情思"读去声。
  - 骑：名词"坐骑"读去声。
  - 王：动词"称王"读去声。
  - 衣：动词"穿衣"读去声。
  - 为：介词"为了"读去声。
  - 相：互相读平声；宰相、相貌读去声。
  - 中：中间读平声；射中读去声。
  - 胜：胜任读平声；胜利读去声。
  - 应：应当读平声；应答读去声。
  - 教：使、让读平声；教化读去声。
  - 重：重复读平声；轻重读上声或去声。
  - 长：长短读平声；生长读上声。

## 6. 入声字

普通话里已经没有入声。古代的入声字在平水韵里一律算仄声，其中有不少今天读阴平或阳平，凭普通话语感最容易判错。常见的有：

> 一 七 八 十 白 石 竹 国 学 节 急 德 福 读 族 杰 舌 结 积 极 及 集 习 席 夕 惜 息 失 实 食 识 出 屋 黑 发 杂 局 菊 桌 觉 阁 格 合 活 拍 杀 插 敌 笛 别 独 足 蝶 薄 雀 鹤 折 酌

这份清单只是提醒，不是全部。以 `meter.py lookup 字` 的结果为准。

## 7. 平水韵与新韵

- **平水韵**（默认）：古典诗词的通行标准。入声字归仄，韵部分得细（平声三十部）。
- **中华新韵**：按普通话读音分平仄（阴平、阳平算平，上声、去声算仄），韵部按普通话韵母分为十四部。适合不熟悉古音的读者，或者用户明确要求用新韵的时候。用 `--rhyme xinyun`。
- 一首诗只用一种韵书，不要混用。交付时在格律简评里写明用的是哪一种。
- 用户写现代题材、又不懂古音时，可以问一句"用平水韵还是新韵"；用户无所谓的话，默认平水韵。

## 8. 选韵

- 宽韵（东、支、先、阳、庚、尤、真等）可用的字多，好写；窄韵（江、佳、肴、覃、咸等）难写，容易凑韵。
- 选韵还要看情绪：响亮的韵写豪情，细腻的韵写柔情（见 `craft.md` 第 7 节）。
- `python3 scripts/meter.py rhymes 下平七阳` 列出该韵部按常用程度排序的字。数量可以调：`--common 120`；`--all` 列出全部。

## 9. 对仗

律诗中间两联必须对仗（详见 `craft.md` 第 3 节）。对仗的平仄是自动满足的：上下句按谱写，平仄自然相反。脚本不检查对仗是否工整，这一项需要自己检查：

- 词性是否相对。
- 结构是否相同。
- 有没有合掌。
- 两联的内容是否错开（一联写景一联写情，或者一联写大一联写小）。

## 10. 用脚本检查

```bash
python3 scripts/meter.py check "全诗，用标点或换行分句"
python3 scripts/meter.py check --form 七律 "……"          # 指定体裁
python3 scripts/meter.py check --rhyme xinyun "……"        # 用新韵
python3 scripts/meter.py check --json "……"               # 输出 JSON，便于程序读取
python3 scripts/meter.py lookup 看                       # 查一个字的平仄和韵部
python3 scripts/meter.py annotate "任意文本"              # 只逐字标出平仄
```

报告里，○ 表示平，● 表示仄，◐ 表示多音字。结论分三档：合律、小疵、不合律。交付时把结论用一两句白话写进格律简评，例如："平水韵，下平七阳，七律平起首句入韵，合律；'看'字此处读平声。"
