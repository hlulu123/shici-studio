# 怀古・咏史

站在古迹前，或者读到一段历史，写下今人对古事的感慨。好的怀古诗不复述历史，而是写出"今天的我"在这段历史面前看到了什么。

## 判断信号

- 用户游览古迹：古城、古战场、故居、陵墓、旧宫殿、名楼。
- 用户读史有感：看了某段历史、某部史书，想写点什么。
- 用户想写某位历史人物：评说他、怀念他，或者借他说自己。
- 用户提到某个朝代、某场战役、某个历史事件。
- 如果写的是当代某个具体的人（同事、亲友），转 `dingchang.md` 或 `songbie.md`。

## 立意方法

- **物是人非、江山依旧**：山河不变，人事已非，用不变的景反衬变化的人世。刘禹锡"山围故国周遭在，潮打空城寂寞回"。
- **以小物见兴亡**：用一个小东西写朝代的兴衰。刘禹锡"旧时王谢堂前燕，飞入寻常百姓家"，一只燕子写尽世家没落。
- **借古讽今、借古喻今**：说古代的事，指向今天的事。杜牧"商女不知亡国恨，隔江犹唱后庭花"。
- **翻案**：对历史人物或事件做出与众不同的评价。杜牧《题乌江亭》说项羽"卷土重来未可知"；王安石《乌江亭》却说"肯与君王卷土来"。
- **人物评说**：评一个历史人物的功过、遗憾。杜甫《蜀相》"出师未捷身先死，长使英雄泪满襟"。
- **借古人自况**：借古人的遭遇写自己。辛弃疾"凭谁问：廉颇老矣，尚能饭否？"
- **假设之问**：设想历史换一种走向。杜牧"东风不与周郎便，铜雀春深锁二乔"。

## 要问的素材

- 写哪处古迹、哪位人物、哪段历史？
- 你在现场看到了什么？要现场的细节：残碑、游客、一棵老树、夕阳下的城墙。
- 这段历史里最打动你的是哪一点？
- 你由此想到了今天的什么，或者自己的什么？

历史事实（人名、年代、地名、事件经过）拿不准时，先联网核对。怀古诗里史实出错是硬伤。

## 章法参考

下面是前人常见的几种走法，帮你理解这一类诗怎么布局。写的时候跟着情绪走，不必逐句对号；初稿卡住了，或者推敲时觉得结构散，再回来参考。

- **今景 → 古事 → 感慨**：先写眼前古迹，再写当年的事，最后落到感慨。这是最常见的结构。
- **古事 → 今景 → 感慨**：先写当年的盛况，再写如今的荒凉，反差强烈。
- **律诗**：
  - 首联：登临入题。
  - 颔联、颈联：一联写古，一联写今，形成对照。
  - 尾联：感慨。
- **绝句**：
  - 前两句：今景。
  - 第三句：转入古事。
  - 第四句：用一个小物或一个反差收住。
- **词**：上片写景、怀古人，下片写感慨、写自己。苏轼《念奴娇・赤壁怀古》、辛弃疾《永遇乐・京口北固亭怀古》都是范本。

## 推荐体裁和风格

- 体裁：
  - 七律（首选，最能承载历史的厚重）
  - 七绝
  - 词：念奴娇、永遇乐、水调歌头、满江红、桂枝香
- 风格：
  - 沉郁（`styles/chenyu.md`）
  - 豪放（`styles/haofang.md`）
  - 骈俪典雅（`styles/pianli.md`）：适合正式场合、写名楼名胜
- 选韵：沉郁可以用尤、侵、寒等韵；豪放用阳、东等韵。

## 用典建议

- 怀古诗本身就是在用史。见 `allusions.md`"怀古・兴亡"一节：王谢乌衣、后庭花、铜雀台、易水、乌江、黍离、新亭对泣、金谷园、麋鹿游姑苏台。
- 史实要准。人名、年代、地名必须核对，拿不准就联网查（见 `yongdian.md` 的查证流程）。
- 与这处古迹直接相关的人和事，比泛泛的兴亡典更有力。写滕王阁就用王勃，写赤壁就用周瑜、苏轼。

## 常见坑

- **史实错误**：人名、年代、事件张冠李戴。
- **只复述历史**：把历史事件写成四句话，没有今人的眼光和感慨。
- **感慨陈旧**："英雄何处""浪淘尽"这类套话。找一个只属于你这次登临的感受。
- **空洞的道德说教**：结尾一句"以史为鉴"，谁都会说。怀古也可以直接下判断，杜牧"东风不与周郎便，铜雀春深锁二乔"就是议论，好在借具体的人和事说出来。
- **今古腔调失衡**：前面写得很古雅，结尾突然冒出一句今天的大白话（谐趣的写法除外）。

## 公版范例

- 刘禹锡《乌衣巷》："朱雀桥边野草花，乌衣巷口夕阳斜。旧时王谢堂前燕，飞入寻常百姓家。"
- 刘禹锡《石头城》："山围故国周遭在，潮打空城寂寞回。淮水东边旧时月，夜深还过女墙来。"
- 杜牧《泊秦淮》："烟笼寒水月笼沙，夜泊秦淮近酒家。商女不知亡国恨，隔江犹唱后庭花。"
- 杜牧《赤壁》："折戟沉沙铁未销，自将磨洗认前朝。东风不与周郎便，铜雀春深锁二乔。"
- 杜牧《题乌江亭》："胜败兵家事不期，包羞忍耻是男儿。江东子弟多才俊，卷土重来未可知。"
- 李白《越中览古》："越王勾践破吴归，义士还家尽锦衣。宫女如花满春殿，只今惟有鹧鸪飞。"
  - 前三句写盛，末句一转写衰。
- 杜甫《蜀相》（节选）："出师未捷身先死，长使英雄泪满襟。"
- 李商隐《贾生》："宣室求贤访逐臣，贾生才调更无伦。可怜夜半虚前席，不问苍生问鬼神。"
- 苏轼《念奴娇・赤壁怀古》（节选）："大江东去，浪淘尽，千古风流人物。"
- 辛弃疾《永遇乐・京口北固亭怀古》（节选）："想当年，金戈铁马，气吞万里如虎……凭谁问：廉颇老矣，尚能饭否？"
