# 诗的类型：总览与判断

写诗的第一步是判断用户想写哪一类诗。类型决定立意方法、要问的素材、推荐的体裁和风格。确定类型后，读对应的文件。

每个类型文件都有相同的八个栏目：判断信号｜立意方法｜要问的素材｜章法参考｜推荐体裁和风格｜用典建议｜常见坑｜公版范例。

## 怎么判断

按下面的顺序看：

1. **场合和对象优先。** 只要用户提到了明确的场合或对象，先按场合判断：
   - 生日、婚礼、开业 → 祝颂
   - 送人远行 → 送别
   - 在活动上为一个人开场、讲他的事迹 → 定场诗
2. **再看写什么。** 写一件事、一处景、一样物、一个人、一段史、一个道理，分别对应记事、写景、咏物、定场、怀古、言志。
3. **最后看情绪。** 以情绪为主、事件只是引子的，归入抒情的三个子类之一。

几组容易混淆的情况：

- **意气风发和言志**：此刻的痛快、得意 → 意气风发；对未来的抱负或人生的道理 → 言志。两者经常兼有，以占主导的为准，另一类的方法可以借用。
- **记事和写景**：重点在人和事 → 记事；重点在风景 → 写景。
- **定场诗和祝颂**：重点是把一个人的事迹、志气立起来 → 定场诗；重点是送上祝福 → 祝颂。寿宴开场念的诗常常两者兼有，可以先写人、末句再落到祝福。
- **愁怀和讽喻**：真心难过 → 愁怀；带着调侃、自嘲 → 讽喻・谐趣。

## 混合与对不上

- **混合**：先定一个主类型来决定章法，再从其他类型借方法。
- **对不上**：不要硬套。直接从用户原话里提炼一句话立意（见 `liyi.md` 第 7 节），然后自由选择体裁和风格。

## 拿不准时问一次

用户的话太短、无法判断时，问一个简短的问题，给两三个最可能的方向。例如：

> 你更想写成哪一种？
> A. 记录这一天的生活小诗
> B. 抒发此刻的豪情
> C. 送给某个人的赠诗

只问一次。用户回答后，缺的其他信息按默认值补齐，不再连续追问。
