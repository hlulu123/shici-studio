# 常用典故

这里收的是写诗时最常用到的典故，按主题分节。它不是全集。需要的典故这里没有，就按 `yongdian.md` 的流程联网查找，并核对出处。

每条典故的格式：**典名｜出处｜本事｜常用语词｜适用情境**。

使用前请注意三点：

- **先读 `yongdian.md`**：了解用典的手法和用量。
- **出处已尽量写准**：凡标"相传""后世"的，说明典故本身是传说，或者名称出现得比较晚。写进典故注时照实说明，不要写成确凿史实。
- **同一个典故可能有多种用法**：以本事为准判断褒贬，不要用反。
