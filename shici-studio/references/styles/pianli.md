# 骈俪典雅（滕王阁序式）

王勃《滕王阁序》式的写法：句句对仗，典故繁密而贴切，辞藻富丽，声调铿锵。它适合庄重的场合，也适合想把一件事写得厚重、写得有来历的时候。

## 基调

典雅、富丽、庄重、工整。表面华美，内里要有一条真情的主线。《滕王阁序》写到后半，转入"关山难越，谁悲失路之人"的身世之感，才使全篇有了魂。

## 代表诗人

- **王勃**：《滕王阁序》，以及《滕王阁诗》"阁中帝子今何在？槛外长江空自流"。
- **骈文传统**：庾信、徐陵、骆宾王。
- **诗中的典丽一路**：初唐四杰；李商隐（他本身也是骈文高手）；辛弃疾那种用典密集的词。

## 意象库

- **地望**：星野（"星分翼轸"）、山川（"三江""五湖""衡庐"）、古迹、名楼。
- **宴集**：高朋、胜友、清风、白云、纤歌、樽酒。
- **自然大景**：落霞、孤鹜、秋水、长天、渔舟、雁阵。
- **人物**：历史名人作比附，如徐孺、陈蕃、孟尝、阮籍、终军、宗悫。
- **色彩与宝物**：紫电、青霜、丹、翠、金、玉。

## 用字

- **四六句**：四字句、六字句交替使用。
- **典雅的双音词**：襟、带、控、引、俨、骖、腾、凌、遄、萃、赊。
- **对仗词群**：方位对方位，数字对数字（三江对五湖），颜色对颜色，人名对人名。
- **虚字领起，连缀段落**：嗟乎、所赖、是以、至若、况、于是、呜呼、敢竭、请洒。
- **声调**：句脚平仄大体交替，读来抑扬有致（见 `forms/pianwen.md`）。

## 句法章法

- **隔句对**：四六与四六成对。"物华天宝，龙光射牛斗之墟；人杰地灵，徐孺下陈蕃之榻。"
- **当句对**：句内自对。"襟三江而带五湖"。
- **典故对典故**："冯唐易老，李广难封"；"屈贾谊于长沙，非无圣主；窜梁鸿于海曲，岂乏明时"。
- **骈中有散**：段落之间用散句或虚字过渡，避免板滞。
- **《滕王阁序》的章法**（可借来写序文、致辞）：
  1. 点地：豫章故郡，洪都新府。
  2. 宾主人物：都督阎公、宇文新州、腾蛟起凤、紫电青霜。
  3. 时令景色：时维九月，序属三秋；落霞孤鹜。
  4. 宴游之乐：遥襟甫畅，逸兴遄飞。
  5. 兴尽悲来：天高地迥，觉宇宙之无穷。
  6. 身世之感：关山难越，谁悲失路之人；冯唐易老，李广难封。
  7. 言志：老当益壮，宁移白首之心？穷且益坚，不坠青云之志。
  8. 谦辞作结、赋诗：一言均赋，四韵俱成。
- **用到诗里**：律诗颔联、颈联用典对；首尾联可以散一些，留出呼吸。

## 宜配体裁

- 骈文短序、铭、短赋，见 `forms/pianwen.md`。适合婚礼致辞、毕业序、周年庆、宴集序、纪念文章。
- 七律、五律：颔联、颈联用典对，最见功力。
- 长联：见 `forms/duilian.md`。
- 庄重的定场诗、祝颂诗：如颁奖、致敬师长、寿诞。

## 避免

- **堆典不切题**：典故密不等于好，每一个典故都要和这件事、这个人、这个地方相关。
- **典故冷僻**：读者看不懂就失效。骈文可以用多一点典故，但要附注。
- **合掌**：上下句意思重复，是骈文最常见的毛病（见 `craft.md` 第 3 节）。
- **有句无篇**：只有华丽的句子，没有情感主线。通常要有一个"转"，比如从乐到悲，或者从景到志。
- **只用四字成语凑对**：成语对成语，像拼图，没有气。
- **用错典故的褒贬**：见 `yongdian.md` 第 4 节。

## 公版例句

- 王勃《滕王阁序》（节选）：
  - "豫章故郡，洪都新府。星分翼轸，地接衡庐。襟三江而带五湖，控蛮荆而引瓯越。物华天宝，龙光射牛斗之墟；人杰地灵，徐孺下陈蕃之榻。"
  - "落霞与孤鹜齐飞，秋水共长天一色。渔舟唱晚，响穷彭蠡之滨；雁阵惊寒，声断衡阳之浦。"
  - "遥襟甫畅，逸兴遄飞。爽籁发而清风生，纤歌凝而白云遏。睢园绿竹，气凌彭泽之樽；邺水朱华，光照临川之笔。"
  - "天高地迥，觉宇宙之无穷；兴尽悲来，识盈虚之有数。"
  - "关山难越，谁悲失路之人？萍水相逢，尽是他乡之客。"
  - "嗟乎！时运不齐，命途多舛。冯唐易老，李广难封。屈贾谊于长沙，非无圣主；窜梁鸿于海曲，岂乏明时？"
  - "老当益壮，宁移白首之心？穷且益坚，不坠青云之志。酌贪泉而觉爽，处涸辙以犹欢。北海虽赊，扶摇可接；东隅已逝，桑榆非晚。孟尝高洁，空余报国之情；阮籍猖狂，岂效穷途之哭！"
  - "无路请缨，等终军之弱冠；有怀投笔，慕宗悫之长风。"
  - "杨意不逢，抚凌云而自惜；钟期既遇，奏流水以何惭？"
- 王勃《滕王阁诗》（节选）："阁中帝子今何在？槛外长江空自流。"
- 刘禹锡《陋室铭》（节选）："山不在高，有仙则名。水不在深，有龙则灵。斯是陋室，惟吾德馨。"

## 附：《滕王阁序》用典拆解

学用典最好的办法，是看王勃怎么用。下表列出几处典型用法：

| 原句 | 典故 | 出处 | 手法 |
|---|---|---|---|
| 龙光射牛斗之墟 | 丰城剑气 | 《晋书・张华传》 | 暗用：不点人名，借宝剑紫气写此地物产之华 |
| 徐孺下陈蕃之榻 | 陈蕃为徐稚设榻 | 《后汉书・徐稚传》 | 明用：借古人写此地人杰、主人好客 |
| 睢园绿竹，气凌彭泽之樽 | 梁孝王睢园；陶渊明（曾任彭泽令）好酒 | 史传；陶渊明诗文 | 叠用：两典一句，写宴会的雅与酒兴 |
| 邺水朱华，光照临川之笔 | 曹植《公宴》"朱华冒绿池"；谢灵运（曾任临川内史） | 曹植诗；《宋书・谢灵运传》 | 叠用：写在座诸人的文采 |
| 冯唐易老，李广难封 | 冯唐、李广 | 《史记》 | 明用、对用：写怀才不遇 |
| 屈贾谊于长沙……窜梁鸿于海曲 | 贾谊被贬、梁鸿避居 | 《史记》《后汉书》 | 明用、隔句对：用贤人失意写自己的处境，又说"非无圣主"，分寸得体 |
| 酌贪泉而觉爽 | 吴隐之饮贪泉而不改其清 | 《晋书・吴隐之传》 | 反用：贪泉不能让我变贪，写自己的操守 |
| 处涸辙以犹欢 | 涸辙之鲋 | 《庄子・外物》 | 反用：身处困境仍然乐观 |
| 北海虽赊，扶摇可接 | 鲲鹏扶摇 | 《庄子・逍遥游》 | 化用：目标虽远，乘风可达 |
| 东隅已逝，桑榆非晚 | 失之东隅，收之桑榆 | 《后汉书・冯异传》 | 化用：错过了早年，晚年仍有可为 |
| 孟尝高洁，空余报国之情 | 东汉孟尝 | 《后汉书・循吏列传・孟尝》 | 明用：以清廉而不被重用的古人自比 |
| 阮籍猖狂，岂效穷途之哭 | 阮籍穷途而哭 | 《晋书・阮籍传》 | 反用：不学阮籍，表明不肯消沉 |
| 无路请缨，等终军之弱冠 | 终军请缨 | 《汉书・终军传》 | 明用：说自己与终军同龄，却无从请缨 |
| 有怀投笔，慕宗悫之长风 | 班超投笔、宗悫长风 | 《后汉书・班超传》《宋书・宗悫传》 | 叠用：一句暗含两典 |
| 杨意不逢……钟期既遇 | 杨得意荐相如；钟子期知音 | 《史记》；《列子》 | 对用：上句叹无人引荐，下句喜遇知音 |
| 落霞与孤鹜齐飞，秋水共长天一色 | 化庾信《马射赋》句 | 庾信《马射赋》 | 化用：句式相近，境界远胜 |

**写法上的启发**：

1. 王勃用典始终围绕一条主线：此地之胜，宴会之乐，自己的失意，自己的不屈。典故再多也不散。
2. 明用、暗用、反用、化用交替出现，避免单调。
3. 写自己的失意时，用"非无圣主""岂乏明时"把分寸拿住，悲而不怨。
4. 用反用来表态，比如"酌贪泉而觉爽""岂效穷途之哭"，最见个性。
