# 改诗与校律

用户拿来一首诗（自己写的、朋友写的、AI 写的），要你校格律、提修改意见或直接改。核心原则是：**尊重原作者**。保留原作的立意和最好的句子，按用户要的幅度改，每一处改动都说清楚理由。

## 1. 先弄清用户要什么

| 用户的说法 | 模式 | 改动幅度 |
|---|---|---|
| "帮我看看格律对不对""哪里不合律""有没有出韵" | 校律 | 只指出问题，给最小改动的方案 |
| "改得合律""修一下平仄" | 只修格律 | 最小，尽量只换字，不动意思 |
| "帮我润色""改得更好""提提意见" | 炼字提升 | 中等，换陈词、炼动词、调句序，保留结构和立意 |
| "改成豪放一点""改成李白那种风格" | 换风格 | 较大，保留立意和核心意象，重写语气、意象和句法 |
| "改成七绝""这首现代诗改成古诗" | 换体裁 | 大，保留立意和素材，按新体裁重写 |
| "帮我改改"（没说怎么改） | 综合 | 先修硬伤（格律、不通），再提升，给两到三个版本 |

用户没说清楚时，按"综合"处理，并在开头用一句话说明你的理解。

## 2. 流程

1. **读懂原作**：
   - 它属于哪一类诗？用 `types/` 判断。
   - 立意是什么？
   - 哪几句最好？这几句要尽量保留。
   - 作者想要什么效果？
2. **跑脚本**：
   - 格律诗：`python3 scripts/meter.py check "原诗"`；词：加 `--form 词:词牌名`；对联：加 `--form 对联`。
   - 撞句：`python3 scripts/dupcheck.py "原诗"`。
3. **诊断**，按下面的顺序：
   1. 格律硬伤：出韵、失粘、失对、孤平、三平尾、字数不对。
   2. 句子不通、用词错误、典故用错。
   3. 立意：是否清楚，有没有转折和落点。
   4. 章法：起承转合是否到位，有没有合掌。
   5. 字句：陈词套语、意象堆砌、凑韵、结尾说教（对照 `craft.md` 第 10 节）。
4. **按模式修改**：先改硬伤，再按用户要的幅度提升。
5. **重新跑脚本**，证明修改后合律、没有撞句。
6. **输出**（格式见第 4 节）。

## 3. 常见问题的修法

| 问题 | 修法 |
|---|---|
| 出韵 | 把出韵的韵脚字换成同韵部的字。用 `meter.py rhymes 韵目` 找候选字；如果换不了，就整联重写，或者全诗换韵 |
| 失粘、失对 | 改动该句第二字（七言还有四、六字）的平仄；或者调换一联上下句的顺序 |
| 孤平 | 五言把第一字（七言第三字）换成平声；或者把五言第三字（七言第五字）换成平声，构成拗救 |
| 三平尾 | 把五言第三字（七言第五字）换成仄声 |
| 拗句没有救 | 在对句救：五言对句第三字（七言第五字）改用平声 |
| 重字 | 换掉其中一处，用近义字或换一个意象 |
| 多音字读音与字义不合 | 按字义确定读音；如果读音不合律，就换字 |
| 撞句 | 改写撞到的句子；如果是有意化用，在说明里注明 |
| 合掌 | 一句保留，另一句改写成另一个侧面 |
| 意象堆砌 | 删去一两个，留下主意象；腾出来的位置写细节 |
| 陈词套语 | 换成具体的物、动作、声音 |
| 结尾空洞说教 | 可以改成以景结情、一个动作或一个问句；也可以保留直说，把话说得更具体、更有分量 |
| 凑韵 | 换韵脚字，或者重写这一句，让韵脚字成为意思所需 |

## 4. 输出格式

```
【诊断】
（一到三条最主要的问题，用白话说：哪个字、什么问题、为什么）

【修改稿】
（修改后的全诗。如果有多个版本，标出版本一、二、三，并用一句话说明各自的侧重）

【改动对照】
原句 → 改句 ｜ 理由
……

【格律】
（脚本结论，一两行；多音字的读法说明）
```

说明：

- 只校律时，可以不给修改稿，只给诊断和每处的修改建议。
- 不需要改的地方也可以说一句。比如"这首是古风，不用按近体格律要求"，或者"第三句的拗是唐人常用的特拗，不必改"。
- 语气要尊重：指出问题，也肯定好的地方。

## 5. 示例

原诗（自拟，七绝）：

> 独上高楼望远山，白云深处鸟飞还。秋风吹落千山叶，满目萧条不忍看。

脚本报告：

- 错误：第四句韵脚"看"属上平十四寒，与"山""还"所在的上平十五删不同部（邻韵），出韵。
- 小疵："山"字出现两次（重字）。
- `dupcheck.py` 另外报出："独上高楼望"五字与李白《金陵城西楼月下吟》"独上高楼望吴越"相同。

修改（只修格律和硬伤）：

> 独倚危楼望远山，白云深处鸟飞还。秋风吹落千林叶，暮色苍茫掩旧关。

改动对照：

- 独上高楼 → 独倚危楼 ｜ 避开与李白句子撞句，平仄不变。
- 千山叶 → 千林叶 ｜ 避免与首句"远山"重字，平仄不变。
- 满目萧条不忍看 → 暮色苍茫掩旧关 ｜ 原韵脚"看"出韵，换成同属十五删的"关"；把直说的"不忍看"改为以景结情，萧瑟之感留在暮色里。

格律：平水韵，上平十五删，七绝仄起首句入韵，合律。

如果用户要"润色提升"，还可以进一步改动意象和句法。比如第二句"白云深处"是很常见的说法，可以换成更具体的景。这时给出两到三个版本，让用户选。

## 6. 注意

- **不要把作者的诗改成你自己的诗**：除非用户要求重写，否则保留原作至少一半的句子和全部核心意象。
- **不要无中生有地挑错**：古风、词、现代诗不能按近体格律判；用新韵写的诗，不能按平水韵判。先确认作者用的是哪种体裁、哪种韵书；不确定就问一句，或者两种都检查一遍，分别说明结论。
- **名家作品**：用户拿古人的名作来问格律时，说明它为什么合律，或者为什么是拗体、古体，不要"修改"名作，除非用户明确只是想做练习。
- **他人作品**：如果用户说明是朋友的诗，修改建议的语气要更委婉，因为这些意见可能会被转达给作者。
