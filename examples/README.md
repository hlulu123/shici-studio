可以留意几处：

- **立意先行**：馄饨那首把泪意推给汤里的热气；录取那首用一只鸟从“敛翼”写到“一鸣”；歌行用大鹏一个意象贯穿六段。
- **典故注明出处**：每个典故都写了书名、篇名和原文短句。
- **不编造事实**：用户没给的细节，交付时会说明哪些是按常情设想的，可以换成真实的。
